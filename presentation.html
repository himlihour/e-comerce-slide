01 - កំណត់ Business

Business Strategy, Products, Target Audience & Revenue Model
1. Business Name & Idea

ភោជនីយដ្ឋាន ភូមិយើង

ផ្តល់ជូននូវម្ហូបខ្មែរស្រុកស្រែរសជាតិដើម តាមរយៈគេហទំព័រកម្ម៉ង់ម្ហូបទំនើប ងាយស្រួល ទាំងញ៉ាំនៅហាង និងដឹកជញ្ជូនដល់ផ្ទះ។

2. Products / Services

មុខម្ហូប ១៥៩ មុខ (១៤ ប្រភេទ)

  • House Specials: មុខម្ហូបពិសេសប្រចាំហាង
  • សាច់មាន់-ទា, សាច់គោ: ចៀន ដុត ឆា ឡុកឡាក់
  • គ្រឿងសមុទ្រ & ត្រី: បង្គា ក្ដាម ត្រីដុត
  • សម្ល & ស៊ុប: សម្លកកូរ ម្ជូរគ្រឿង ស៊ុបដីឥដ្ឋ
  • ភេសជ្ជៈ: ទឹកផ្លែឈើ ទឹកកំប៉ុង ស្រាបៀរត្រជាក់
3. Target Customer

អតិថិជនគោលដៅ ៤ ក្រុម

  • ក្រុមគ្រួសារ & មិត្តភក្តិ: ញ៉ាំជុំគ្នាទាំងនៅហាង និងទៅផ្ទះ
  • បុគ្គលិកការិយាល័យ: កម្ម៉ង់អាហារថ្ងៃត្រង់រហ័សទាន់ចិត្ត
  • ភ្ញៀវទេសចរ & បរទេស: ងាយយល់តាម ២ ភាសា (ខ្មែរ/EN)
  • ភ្ញៀវញ៉ាំនៅហាង: កម្ម៉ង់ផ្ទាល់តាមទូរសព្ទតាមលេខតុ
4. Customer Need (បញ្ហាដោះស្រាយជូនអតិថិជន)
  • លែងបារម្ភរឿងចាំ Menu ក្រដាសយូរ ដោយអាចឆែកតម្លៃច្បាស់លាស់ ($) ភ្លាមៗ
  • មើលរូបភាពម្ហូបពិតច្បាស់ៗពីច្រើនជ្រុង (Multi-angle photos) មិនច្រឡំមុខម្ហូប
  • ជ្រើសរើសរសជាតិបានតាមចិត្ត (មិនដាក់ទឹកកក/ទឹកកក, ជ្រើសរើសទឹកជ្រលក់, បន្ថែមបាយ/ពងទា)
5. Business Model (ប្រភពចំណូល)
  • ការលក់ម្ហូប និងភេសជ្ជៈផ្ទាល់: Food & Beverage Margins លើមុខម្ហូបទាំងអស់
  • ការលក់បន្ថែមគ្រឿងផ្សំពិសេស: Add-ons (ពងទាចៀន, ទឹកជ្រលក់ពិសេស, បាយ)
  • សេវាដឹកជញ្ជូន: Delivery Fees គិតតាមចម្ងាយដឹក
  • កញ្ចប់សេវាកម្មវិធី: Catering Packages សម្រាប់ក្រុមហ៊ុន និងជប់លៀង

02 - កំណត់ Process

សកម្មភាពចម្បង, មុខងារ Platform, Customer Journey, Business Flow
1. Main Activities (សកម្មភាពចម្បង)
  • ការថែទាំបញ្ជីមុខម្ហូប និងរូបភាព: Menu Curation & Food Photography
  • ទទួលការកម្ម៉ង់ និងចម្អិនក្នុងផ្ទះបាយ: Cook Timing: 10-25 នាទី
  • ការរត់តុ ឬបញ្ជូនឱ្យអ្នកដឹក: Dine-in Serving or Courier Dispatch
  • ការទូទាត់ប្រាក់ និងផ្ទៀងផ្ទាត់: ABA KHQR Instant Payment & Cash Tracking
2. Main Features (មុខងារសំខាន់ៗ)
  • Multi-Angle Photo Carousel: អូសស្លាយមើលរូបម្ហូបពិតប្រាកដយ៉ាងរលូន
  • Choice Selector ($0) & Paid Add-ons: រើសជម្រើសឥតគិតថ្លៃ និងបន្ថែមគ្រឿងគិតលុយ
  • Contextual Recommendations: បង្ហាញម្ហូបដែលអ្នកប្រហែលជាចូលចិត្តក្នុងប្រភេទដូចគ្នា
  • Real-Time Cart Drawer: គណនាតម្លៃសរុប និងថ្លៃសេវាដឹកភ្លាមៗ
  • Admin Management Portal: ផ្ទាំងគ្រប់គ្រងការលក់ និងប្តូរស្ថានភាពកម្ម៉ង់
3. Customer Journey (ដំណើរការរបស់អតិថិជន)
1
ស្វែងរក (Discover):
ចូលគេហទំព័រ រើសភាសា ស្វែងរកតាមប្រភេទម្ហូប ឬវាយឈ្មោះមុខម្ហូប។
2
មើលលម្អិត & ជម្រើស:
ចុចមើលរូបភាពច្រើនជ្រុង រើសទឹកជ្រលក់ កម្រិតទឹកកក ឬបន្ថែមពងទា/បាយ។
3
ដាក់ក្នុងកន្ត្រក & Checkout:
ពិនិត្យតម្លៃសរុប ជ្រើសរើសលេខតុ (ញ៉ាំនៅហាង) ឬអាសយដ្ឋានដឹកជញ្ជូន។
4
ទទួលលេខ Order & តាមដាន:
ទទួលបាន Order ID ផ្ទះបាយចាប់ផ្តើមចម្អិន និងតាមដានរហូតដល់ទទួលបានម្ហូប។
4. Basic Business Process (ដំណើរការអាជីវកម្ម)

ភ្ញៀវកម្ម៉ង់លើ Web ➔ API បញ្ជូនចូល DB ➔ ផ្ទះបាយទទួល Order ➔ ចម្អិន & លើកជូន ➔ ទូទាត់ជោគជ័យ

03 - Website Planning

រចនាសម្ព័ន្ធគេហទំព័រ (Basic Sitemap) & លំហូរអ្នកប្រើប្រាស់ (Basic User Flow)
Basic Sitemap Architecture

រចនាសម្ព័ន្ធគេហទំព័រ ភូមិយើង

└── Home Page (/)
    ├── Header: Logo ភូមិយើង, Search, ប្តូរភាសា (KH/EN), Cart Badge
    ├── Sidebar Menu: បែងចែកមុខម្ហូបទាំង ១៤ ប្រភេទ
    ├── Product Grid: កាតមុខម្ហូប (រូបភាព, ឈ្មោះ, តម្លៃ, រយៈពេលចម្អិន)
    ├── Food Detail Modal: ស្លាយរូបភាព, Add-ons, You May Also Like
    ├── Cart Drawer & Checkout: លេខតុ / ទីតាំងដឹក, ABA KHQR / Cash
    └── Customer Orders: តាមដានស្ថានភាព Order ផ្ទាល់
└── Admin Dashboard (/admin)
    ├── ស្ថិតិការលក់: Total Revenue, Total Orders
    ├── គ្រប់គ្រង Order: ប្តូរស្ថានភាព Pending ➔ Preparing ➔ Completed
    └── គ្រប់គ្រងមុខម្ហូប: បន្ថែម / កែប្រែ / លុប
Basic User Flow

លំហូរអ្នកប្រើប្រាស់ ៣ ប្រភេទ

Flow A (ភ្ញៀវកម្ម៉ង់ម្ហូប):
ចូល Web ➔ រើសម្ហូប ➔ បន្ថែមជម្រើស/Add-ons ➔ ដាក់ចូលកន្ត្រក ➔ Checkout ➔ បង់ប្រាក់/រើសលេខតុ ➔ កម្ម៉ង់ជោគជ័យ
Flow B (ភ្ញៀវតាមដាន Order):
ចុច "My Orders" ➔ មើលស្ថានភាពផ្ទាល់តាម Order ID (Pending ➔ Preparing ➔ Delivered) ➔ មើលវិក្កយបត្រ
Flow C (អ្នកគ្រប់គ្រងហាង):
ចូល Admin Portal ➔ មើល Order ថ្មី ➔ ចុចប្តូរស្ថានភាពទៅ "Preparing" ➔ "Completed" ➔ ពិនិត្យចំណូលប្រចាំថ្ងៃ

Technical Implementation & Architecture

បច្ចេកវិទ្យាអនុវត្តគម្រោង (Modern Full-Stack Engineering)
Frontend Engine

React 19 + Vite

  • ល្បឿនលឿនបំផុត: Sub-second HMR ជាមួយ Vite 8
  • UI ប្តូរបាន ២ ភាសា: Instant toggle រវាងភាសាខ្មែរ និង English
  • Hardware-Accelerated Carousel: ស្លាយរូបភាពរលូនគ្មានទាក់
  • Responsive 100%: ដំណើរការល្អទាំងលើទូរសព្ទ iPad និងកុំព្យូទ័រ
Backend API

Node.js + Express

  • RESTful API Architecture: Endpoints សម្រាប់ Products, Auth, Orders
  • JWT Authentication: សុវត្ថិភាពខ្ពស់ ផ្ទៀងផ្ទាត់សិទ្ធិអ្នកប្រើប្រាស់
  • Real-Time Updates: Dispatch ស្ថានភាពភ្លាមៗទៅកាន់ផ្ទះបាយ
  • Static Media Serving: បញ្ជូនរូបភាពម្ហូបគុណភាពច្បាស់ត្រឹមត្រូវ
Database Layer

MongoDB + Memory Fallback

  • Mongoose ODM: Schemas សម្រាប់ Products, Users, Categories, Orders
  • Resilient In-Memory Fallback: ធានាថាប្រព័ន្ធដំណើរការ ១០០% ជានិច្ច
  • Data Deduplication: កម្ចាត់រូបភាពស្ទួនចេញអស់ មិនច្រឡំ
